# AutoKiCad: от монтажа к принципиальной схеме

Обычно в EasyEDA и KiCad сначала рисуют схему, а потом плату. Здесь всё как в Tinkercad Circuits:

1. **Монтаж на макетной плате.** Вы ставите компоненты в «реальном» виде (резистор с цветными полосками, светодиод, NE555, Arduino Nano…) прямо в отверстия макетной платы. Ножки в одной полоске соединяются сами, как у настоящей платы. Где нужно, ставите перемычки от отверстия к отверстию.
2. **Схема строится сама**, и её видно справа прямо во время сборки. Программа строит список соединений, расставляет условные обозначения, прокладывает провода, ставит символы GND/+9V и метки цепей.
3. **Экспорт** в KiCad или EasyEDA, где можно продолжить работу: трассировать плату, заказать её и т.д.

## Запуск

**В EasyEDA (основной способ).** Папка `easyeda-extension/` — это расширение для EasyEDA Standard. Установка описана в [easyeda-extension/README.md](easyeda-extension/README.md). Макетка открывается прямо в EasyEDA, компоненты берутся из библиотеки EasyEDA/LCSC (поиск по названию или номеру LCSC), а кнопка «Создать схему в EasyEDA» строит схему в редакторе.

**Отдельно.** Можно открыть `index.html` в браузере (Chrome, Edge, Firefox), без сервера и установки. Здесь доступны встроенные компоненты и экспорт в файлы. Поиск по библиотеке EasyEDA работает только внутри EasyEDA: сервер EasyEDA не принимает запросы с других страниц.
Кнопка «Пример» загружает мигалку на NE555, собранную на макетной плате. «Новый» даёт пустую макетную плату.

## Макетная плата

Плата на 30 столбцов, такая же, как настоящая half-size:
- в каждом столбце отверстия **a–e** соединены между собой, отверстия **f–j** тоже, а канавка посередине их разделяет;
- шины **+** и **−** сверху и снизу соединены по всей длине. Верхние и нижние шины между собой не соединены, для этого ставят перемычки.

Компонент, поставленный на плату, «защёлкивается» ножками в отверстия. Занятые отверстия подсвечиваются зелёным. При наведении на отверстие подсвечивается вся цепь. Плату можно перетаскивать, и компоненты едут вместе с ней. Ножки разных компонентов, поставленные в одну точку, тоже соединяются, так что плата не обязательна.

## Управление

| Действие | Как |
|---|---|
| Добавить компонент | перетащить из левой панели или кликнуть по нему, затем по полю (Shift+клик — поставить несколько) |
| Перемычка / провод | зажать мышь на отверстии или выводе и отпустить на другом. Или кликнуть дважды, при этом клики по пустому месту ставят точки изгиба. Провод к шине «−» становится чёрным, к «+» — красным |
| Режим | «Монтаж», «Монтаж + схема» (рядом, по умолчанию на широком экране), «Схема» |
| Точка изгиба у готового провода | двойной клик по проводу; точки можно перетаскивать |
| Поворот / удаление / копия | `R` / `Del` / `Ctrl+D` |
| Отмена / повтор | `Ctrl+Z` / `Ctrl+Y` |
| Масштаб / сдвиг | колесо мыши / перетаскивание пустого места |
| Цвет нового провода | клавиши `1`…`8` или в свойствах провода |
| Имя цепи | выделить провод → «Имя цепи» (GND, VCC, +5V… превращаются в шины питания) |

На вкладке «Схема» символы можно перетаскивать, провода перестраиваются автоматически. «Авторасстановка» сбрасывает положение символов.

Проект автоматически сохраняется в браузере. «Сохранить» скачивает файл `.akc.json`.

## Экспорт

- **KiCad, готовый проект (`.zip`)**: `.kicad_pro`, схема, библиотека символов `AutoKiCad.kicad_sym` и `sym-lib-table`. Распакуйте архив и откройте `.kicad_pro`. Проверено в KiCad 10.0.6: демо‑схема проходит ERC без ошибок и предупреждений.
- **KiCad, только схема (`.kicad_sch`)**: один файл, символы встроены в него, у компонентов прописаны посадочные места (footprint). EasyEDA Pro импортирует KiCad‑проекты: *Файл → Импорт → KiCad*.
- **EasyEDA Standard (`.json`)**: исходник схемы. В EasyEDA: *Документ → Открыть → EasyEDA Source…* или просто перетащите файл в окно. Набор полей сверен с парсером EasyEDA 6.5.51.
- **Netlist (`.net`)**: список соединений в формате KiCad, для загрузки в редактор плат.
- **SVG**: картинка схемы.

Готовые файлы демо‑проекта во всех форматах лежат в папке `examples/`.

## Как это устроено

```
js/components.js     библиотека: внешний вид (монтаж) + символ (схема) + footprint
js/editor.js         редактор монтажа
js/easyeda-lib.js    библиотека EasyEDA: поиск, загрузка, символ + вид на макетке по посадочному месту
js/netlist.js        провода + полоски макетки + совпадающие ножки → цепи (union-find), имена, проверки
js/schematic.js      автогенерация схемы: расстановка + трассировка
js/schview.js        отрисовка и просмотр схемы
js/export-kicad.js   .kicad_sch и .net
js/export-easyeda.js EasyEDA Standard JSON
js/app.js            интерфейс, история, файлы, пример
easyeda-extension/   расширение EasyEDA: main.js (окно, сборка схемы через API EasyEDA), ui.txt (собранный интерфейс)
tools/build-extension.js  сборка ui.txt из исходников
```

Компоненты из библиотеки EasyEDA — **JLCEDA/EasyEDA Official Library**, https://lceda.cn/ · https://easyeda.com.

**Генерация схемы:**
1. Цепи питания (GND, +5V, VCC… или источник «Питание») рисуются символами питания, а не проводами.
2. Символы расставляются жадным алгоритмом: первым ставится самый связанный компонент, остальные ставятся рядом с теми, с кем у них больше всего общих цепей.
3. Каждая сигнальная цепь соединяется по минимальному остовному дереву Г‑ и Z‑образными проводами. Провода не проходят через корпуса и не касаются чужих цепей, при этом пересечения разрешены. Если путь не найден, вместо провода ставятся метки с именем цепи.
4. Неподключённые выводы помечаются крестиком (no‑connect).

## Добавить свой компонент

В `js/components.js` добавьте объект в `defs`:
- `visual` — как компонент выглядит в монтаже: SVG‑функция `draw` и координаты выводов в пикселях (10px = 2.54 мм). Расстояния между выводами должны быть кратны 10px, чтобы ножки попадали в отверстия макетки. `hit` — область захвата мышью, обычно только корпус;
- `sym` — символ схемы в единицах U (1U = 2.54 мм). Выводы должны стоять на целых координатах, `dir` указывает от точки подключения к корпусу. Для микросхем есть готовый генератор `makeIC(left, right, width)`;
- `footprint` — посадочное место KiCad.
