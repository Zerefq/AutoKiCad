# AutoKiCad: от монтажа к принципиальной схеме

Обычно в EasyEDA и KiCad сначала рисуют схему, а потом плату. Здесь всё как в Tinkercad Circuits:

1. **Монтаж на макетной плате.** Вы ставите компоненты в «реальном» виде (резистор с цветными полосками, светодиод, NE555, Arduino Nano…) прямо в отверстия макетной платы. Ножки в одной полоске соединяются сами, как у настоящей платы. Где нужно, ставите перемычки от отверстия к отверстию.
2. **Схема строится сама**, и её видно справа прямо во время сборки. Программа строит список соединений, расставляет условные обозначения, прокладывает провода, ставит символы GND/+9V и метки цепей.
3. **Печатная плата** — на вкладке «Плата»: детали с настоящими посадочными местами, контур (прямоугольник, круг, сердце), линии связей.
4. **Экспорт** в EasyEDA или KiCad (схема и плата), где можно развести дорожки и заказать плату.

## Запуск

**В EasyEDA (основной способ).** Папка `easyeda-extension/` — это расширение для EasyEDA Standard. Установка описана в [easyeda-extension/README.md](easyeda-extension/README.md). Макетка открывается прямо в EasyEDA, компоненты берутся из библиотеки EasyEDA/LCSC (поиск по названию или номеру LCSC). Кнопка «Создать схему в EasyEDA» строит схему в редакторе, «Создать плату в EasyEDA» — плату.

**Отдельно.** Можно открыть `index.html` в браузере (Chrome, Edge, Firefox), без сервера и установки. Или через локальный сервер: `node tools/serve.js` и открыть адрес, который он напишет (обычно http://127.0.0.1:8765; если порт занят, сервер берёт следующий). Здесь доступны встроенные компоненты и экспорт в файлы. Поиск по библиотеке EasyEDA работает только внутри EasyEDA: сервер EasyEDA не принимает запросы с других страниц.
Программа открывается с пустой макетной платой. Готовые схемы лежат в меню **«Примеры»**:

| Пример | Что показывает |
|---|---|
| Светодиод с резистором | самая простая цепь: батарея, резистор, светодиод |
| Мигалка на NE555 | таймер в режиме генератора |
| Транзисторный ключ | кнопка включает светодиод через NPN-транзистор |
| Сумеречный выключатель | фоторезистор и транзистор: в темноте светодиод горит |
| Стабилизатор 5 В | 7805 делает +5 В из 9 В батареи |
| Arduino Nano: Blink | светодиод на выводе D13 |
| **Example_Heart** | плата-сердце: ATtiny85, 11 адресных светодиодов WS2812B по контуру, две кнопки, USB-C. Макетка на двух больших платах, схема и печатная плата в форме сердца с расстановкой деталей как на фото |
| **Example_Heart_3D** | та же плата-сердце, открывается сразу на вкладке «3D»: фиолетовая плата с деталями, как на фото. В EasyEDA — с настоящими 3D-моделями деталей |

Пример заменяет текущий проект, вернуть прежний можно через `Ctrl+Z`. Эти же примеры лежат файлами в папке `examples/` (*Открыть → .akc.json*). «Новый» даёт пустую макетную плату.

## Макетная плата

Плата на 30 столбцов, такая же, как настоящая half-size (есть и большая — на 60 столбцов):
- в каждом столбце отверстия **a–e** соединены между собой, отверстия **f–j** тоже, а канавка посередине их разделяет;
- шины **+** и **−** сверху и снизу соединены по всей длине. Верхние и нижние шины между собой не соединены, для этого ставят перемычки.

Компонент, поставленный на плату, «защёлкивается» ножками в отверстия. Занятые отверстия подсвечиваются зелёным. При наведении на отверстие подсвечивается вся цепь. Плату можно перетаскивать, и компоненты едут вместе с ней. Ножки разных компонентов, поставленные в одну точку, тоже соединяются, так что плата не обязательна.

## Управление

| Действие | Как |
|---|---|
| Добавить компонент | перетащить из левой панели или кликнуть по нему, затем по полю (Shift+клик — поставить несколько). Поле «Фильтр» над палитрой ищет по названию, номиналу и корпусу |
| Выделение | клик по компоненту; рамка левой кнопкой по пустому месту (выделяются компоненты, целиком попавшие в рамку); `Ctrl`/`Shift`+клик — добавить или убрать; `Ctrl+A` — всё. С `Shift`/`Ctrl` рамку можно начинать и поверх платы |
| Группа | перетаскивание любого выделенного компонента двигает всю группу; `R` поворачивает группу, выводы остаются в отверстиях; стрелки — сдвиг на 0.1" (`Shift` — на 0.5") |
| Копирование | `Ctrl+C` / `Ctrl+V` / `Ctrl+X`, `Ctrl+D` — копия рядом. Копия ставится справа от оригинала; вместе с платой копируются вставленные в неё детали и перемычки |
| Перемычка / провод | зажать мышь на отверстии или выводе и отпустить на другом. Или кликнуть дважды, при этом клики по пустому месту ставят точки изгиба. Провод к шине «−» становится чёрным, к «+» — красным |
| Режим | «Монтаж», «Монтаж + схема» (рядом, по умолчанию на широком экране), «Схема», «Плата», «3D» |
| Точка изгиба у готового провода | двойной клик по проводу; точки можно перетаскивать |
| Поворот / удаление / копия | `R` / `Del` / `Ctrl+D` |
| Отмена / повтор | `Ctrl+Z` / `Ctrl+Y` |
| Масштаб / сдвиг поля | колесо мыши / перетаскивание правой или средней кнопкой (как в EasyEDA), либо `Alt` + левой |
| Цвет нового провода | клавиши `1`…`8` или в свойствах провода |
| Имя цепи | выделить провод → «Имя цепи» (GND, VCC, +5V… превращаются в шины питания) |

На вкладке «Схема» символы можно перетаскивать, провода перестраиваются автоматически. «Авторасстановка» сбрасывает положение символов.

## Печатная плата

Вкладка **«Плата»**. Все детали проекта сразу стоят на плате со своими посадочными местами (площадки, отверстия, шелкография), а голубой пунктир показывает связи, которые нужно развести дорожками.

| Действие | Как |
|---|---|
| Переставить деталь | перетащить мышью (шаг 0.5 мм, с `Alt` — 0.1 мм) или стрелками (0.5 мм, с `Shift` — 2.54 мм); точные X, Y и угол — в панели справа |
| Повернуть | `R` — на 90°, `Shift+R` — на 45° |
| Посадочное место | в панели справа: например, резистор с шагом 10.16 / 7.62 мм, стоячий или SMD 0805 / 0603 |
| Форма платы | в панели справа, когда ничего не выделено: по деталям, прямоугольник, круг, сердце; размер и сдвиг контура; цвет маски (только для вида) |

Посадочные места встроенных деталей взяты из библиотеки KiCad, у деталей из библиотеки EasyEDA/LCSC — их родные. Дорожки программа не прокладывает: это делается в EasyEDA (*Трассировка → Автотрассировка* или вручную) или в KiCad.

## 3D

Вкладка **«3D»** показывает плату в объёме: маска выбранного цвета, площадки, шелкография и детали — резисторы с цветными полосками по номиналу, микросхемы, светодиоды, кнопки, разъёмы. Тяните мышью — вращение, колесо — масштаб, правая кнопка — сдвиг; кнопки «Наклон», «Сверху», «Спереди», «Сбоку» в панели справа.

К каждому посадочному месту привязана 3D-модель из библиотеки EasyEDA, поэтому в EasyEDA (*Вид → 3D-вид*) плата видна с настоящими моделями деталей. В расширении кнопка **«3D-вид в EasyEDA»** создаёт плату и сразу открывает её 3D-вид с тем же цветом маски.

Проект автоматически сохраняется в браузере. «Сохранить» скачивает файл `.akc.json`.

## Экспорт

- **KiCad, готовый проект (`.zip`)**: `.kicad_pro`, схема, плата, библиотека символов `AutoKiCad.kicad_sym` и `sym-lib-table`. Распакуйте архив и откройте `.kicad_pro`. Проверено в KiCad 10.0.6: демо‑схема проходит ERC без ошибок и предупреждений.
- **KiCad, только схема (`.kicad_sch`)**: один файл, символы встроены в него, у компонентов прописаны посадочные места (footprint). EasyEDA Pro импортирует KiCad‑проекты: *Файл → Импорт → KiCad*.
- **EasyEDA Standard (`.json`)**: исходник схемы. В EasyEDA: *Документ → Открыть → EasyEDA Source…* или просто перетащите файл в окно. Набор полей сверен с парсером EasyEDA 6.5.51.
- **EasyEDA Standard — плата (`.json`)**: контур, посадочные места, цепи на площадках, видимые связи. Открывается так же. Проверено в EasyEDA 6.5.60: все детали и цепи на месте.
- **KiCad — плата (`.kicad_pcb`)**: то же для KiCad; входит и в готовый проект (`.zip`). Проверено `kicad-cli pcb drc`: без замыканий и нарушений зазоров. Предупреждение «посадочное место не совпадает с библиотекой» снимается командой *Инструменты → Обновить посадочные места из библиотеки*.
- **Netlist (`.net`)**: список соединений в формате KiCad, для загрузки в редактор плат.
- **BOM (`.csv`)**: перечень элементов, как в EasyEDA. Одинаковые детали идут одной строкой (обозначения, номинал, корпус, посадочное место, количество, номер LCSC). Открывается в Excel.
- **PNG / SVG**: картинка схемы.
- **Печать / PDF**: схема на листе A4; в окне печати можно выбрать «Сохранить как PDF».

## Компоненты

Встроенные: макетные платы на 30 и 60 столбцов, резистор, конденсатор, электролитический конденсатор, катушка индуктивности, кварцевый резонатор, светодиод, диод, стабилитрон, NPN и PNP транзисторы, N-MOSFET, кнопка, переключатель, потенциометр, фоторезистор, пищалка, мотор, батарея, стабилизатор 78xx (выход сам становится цепью +5V/+12V… по номиналу), таймер NE555, операционный усилитель LM358, микроконтроллер ATtiny85, адресный RGB-светодиод WS2812B, разъём USB-C, контакт-отверстие, Arduino Nano, разъёмы 1×2…1×8, символы питания и земли. В EasyEDA к ним добавляется вся библиотека EasyEDA/LCSC через поиск.

Готовые файлы примеров лежат в папке `examples/`: все примеры как проекты (`.akc.json`), мигалка и Example_Heart — ещё и в форматах KiCad и EasyEDA (у сердца — со схемой и платой).

## Как это устроено

```
js/components.js     библиотека: внешний вид (монтаж) + символ (схема) + footprint
js/footprints.js     посадочные места из библиотеки KiCad (собирается tools/build-footprints.js)
js/ee-footprints.js  такие же посадочные места из библиотеки EasyEDA и их 3D-модели (собирается tools/build-ee-footprints.js)
js/examples.js       примеры из меню «Примеры» (компоненты ставятся в отверстия по имени: f14, TP1…)
js/editor.js         редактор монтажа
js/easyeda-lib.js    библиотека EasyEDA: поиск, загрузка, символ + вид на макетке по посадочному месту
js/netlist.js        провода + полоски макетки + совпадающие ножки → цепи (union-find), имена, проверки
js/schematic.js      автогенерация схемы: расстановка + трассировка
js/schview.js        отрисовка и просмотр схемы
js/export-kicad.js   .kicad_sch и .net
js/export-easyeda.js EasyEDA Standard JSON
js/pcb.js            печатная плата: расстановка, контур, площадки с цепями, связи, экспорт в EasyEDA и KiCad
js/pcbview.js        вкладка «Плата»
js/pcb3d.js          вкладка «3D»
js/app.js            интерфейс, история, файлы, пример
easyeda-extension/   расширение EasyEDA: main.js (окно, сборка схемы и платы через API EasyEDA), ui.txt (собранный интерфейс)
tools/build-extension.js  сборка ui.txt из исходников
tools/build-footprints.js сборка js/footprints.js из библиотеки KiCad
tools/build-ee-footprints.js сборка js/ee-footprints.js: подбор посадочных мест EasyEDA по расположению площадок
tools/serve.js       локальный сервер
```

Компоненты из библиотеки EasyEDA — **JLCEDA/EasyEDA Official Library**, https://lceda.cn/ · https://easyeda.com.

Посадочные места встроенных деталей (`js/footprints.js`) — из **KiCad footprint library** (https://gitlab.com/kicad/libraries/kicad-footprints), лицензия CC-BY-SA 4.0 с исключением: платы, сделанные с этими посадочными местами, можно распространять и использовать без ограничений.

**Генерация схемы:**
1. Цепи питания (GND, +5V, VCC… или источник «Питание») рисуются символами питания, а не проводами.
2. Символы расставляются жадным алгоритмом: первым ставится самый связанный компонент, остальные ставятся рядом с теми, с кем у них больше всего общих цепей.
3. Каждая сигнальная цепь соединяется по минимальному остовному дереву Г‑ и Z‑образными проводами. Провода не проходят через корпуса и не касаются чужих цепей, при этом пересечения разрешены. Если путь не найден, вместо провода ставятся метки с именем цепи.
4. Неподключённые выводы помечаются крестиком (no‑connect).

## Добавить свой компонент

В `js/components.js` добавьте объект в `defs`:
- `visual` — как компонент выглядит в монтаже: SVG‑функция `draw` и координаты выводов в пикселях (10px = 2.54 мм). Расстояния между выводами должны быть кратны 10px, чтобы ножки попадали в отверстия макетки. `hit` — область захвата мышью, обычно только корпус;
- `sym` — символ схемы в единицах U (1U = 2.54 мм). Выводы должны стоять на целых координатах, `dir` указывает от точки подключения к корпусу. Для микросхем есть готовый генератор `makeIC(left, right, width)`;
- `footprint` — посадочное место KiCad, `fpAlt` — альтернативы. После добавления выполните `node tools/build-footprints.js`, чтобы посадочное место попало в `js/footprints.js`, затем `node tools/build-ee-footprints.js` — для «Конвертировать в печатную плату» в EasyEDA. Если номера площадок не совпадают с номерами выводов (как у USB-C), задайте `padMap: { площадка: вывод }`.
