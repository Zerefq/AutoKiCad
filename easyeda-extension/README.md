# AutoKiCad — расширение для EasyEDA Standard

Макетная плата прямо в EasyEDA, как в Tinkercad. Вы собираете схему на макетке, а принципиальная схема EasyEDA строится сама. Компоненты берутся из библиотеки EasyEDA/LCSC. В схему они попадают «родными» символами EasyEDA, с корпусом и номером LCSC, так что дальше можно сразу делать плату и заказывать её.

Проверено в EasyEDA Standard 6.5.51 (десктоп).

## Установка (один раз)

1. В EasyEDA: **Дополнительно → Расширения → Настройки расширений…**
2. Нажмите **«Загрузить расширение…»**, затем **«Выберите файлы…»**.
3. Выделите в этой папке все 4 файла: `manifest.json`, `main.js`, `ui.txt`, `icon.svg`.
4. ID подставится сам (`autokicad`). Нажмите **«Загрузить расширение»**.

Расширение запоминается и загружается при каждом запуске EasyEDA.

## Работа

1. Откройте макетку кнопкой с иконкой макетной платы на панели инструментов или через **Дополнительно → AutoKiCad: макетная плата**.
2. Слева, в поле **«Библиотека EasyEDA / LCSC»**, ищите любой компонент по названию или номеру LCSC (`NE555`, `10k 0603`, `C25804`…). Кликните по результату и поставьте компонент на макетку.
   - Выводные детали с шагом 2.54 мм встают в отверстия по своему настоящему посадочному месту.
   - SMD-детали и детали с другим шагом показываются как модуль на переходной плате, с выводами через 2.54 мм.
3. Встроенные компоненты слева (резистор, светодиод, транзисторы, MOSFET, 7805, NE555, LM358, Arduino Nano…) тоже доступны. Готовые схемы лежат в меню **«Примеры»**.
4. Нажмите **«Создать схему в EasyEDA»**. Откроется новая схема с расставленными символами, проводами, символами питания и метками.

Крестик в заголовке окна сворачивает макетку, проект при этом сохраняется.

## Обновление

Если файлы расширения изменились: в **Настройках расширений** удалите AutoKiCad и загрузите его заново, как при установке. Файл `ui.txt` собирается командой `node tools/build-extension.js` из исходников в корне проекта.

## Источник компонентов

Символы и посадочные места загружаются из **JLCEDA/EasyEDA Official Library** — https://lceda.cn/ · https://easyeda.com. Права на библиотеку принадлежат JLCEDA/EasyEDA. По условиям библиотеки её можно использовать в любых, в том числе коммерческих, схемах, когда работа идёт в JLCEDA/EasyEDA.
